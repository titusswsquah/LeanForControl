# Paper-coordinate optimization definitions — 12 items

Source at the pinned snapshot: `LeanForControl/Estimation/ChiProblem.lean`.

## 1. `chiTraj`

```lean
noncomputable def chiTraj (χ₀ : Fin n → ℝ) (ω : ℕ → Fin m → ℝ) :
    ℕ → Fin n → ℝ
  | 0 => χ₀
  | k + 1 => S.A *ᵥ chiTraj χ₀ ω k + S.G *ᵥ ω k
```

**Rendered meaning.** Starting from χ₀, the candidate estimate trajectory follows χ(k+1) = Aχ(k) + Gω(k).

**Paper counterpart.** P_T constrains the decision trajectory by χ⁺ = Aχ + Gω.

## 2. `nominalY`

```lean
noncomputable def nominalY (x₀ : Fin n → ℝ) (k : ℕ) : Fin p → ℝ :=
  S.C *ᵥ (S.A ^ k *ᵥ x₀)
```

**Rendered meaning.** With no process or measurement disturbances, y(k) = CAᵏx₀.

**Paper counterpart.** In the nominal stability analysis the paper assumes y(k) = CAᵏx(0).

## 3. `chiResid`

```lean
noncomputable def chiResid (x₀ χ₀ : Fin n → ℝ) (ω : ℕ → Fin m → ℝ)
    (k : ℕ) : Fin p → ℝ :=
  S.nominalY x₀ k - S.C *ᵥ S.chiTraj χ₀ ω k
```

**Rendered meaning.** The candidate measurement residual is ν(k) = y(k) − Cχ(k), with y fixed to the nominal data from x₀.

**Paper counterpart.** P_T uses y = Cχ + ν, hence ν = y − Cχ. The later stability analysis specializes y to nominal measurements.

## 4. `chiCost`

```lean
noncomputable def chiCost (x₀ xbar χ₀ : Fin n → ℝ)
    (ω : ℕ → Fin m → ℝ) (T : ℕ) : ℝ :=
  quadForm (symmPinv S.hSig0.1) (χ₀ - xbar)
    + ∑ k ∈ Finset.range T,
        (quadForm S.Qi (ω k) + quadForm S.Ri (S.chiResid x₀ χ₀ ω k))
```

**Rendered meaning.** The objective is the Σ₀†-weighted prior mismatch plus T process and measurement-residual quadratic penalties.

**Paper counterpart.** P_T minimizes one half of ‖χ(0)−x̄₀‖² weighted by Σ₀† plus one half of the sum of ‖ω(k)‖² weighted by Q⁻¹ and ‖ν(k)‖² weighted by R⁻¹. Lean omits the common factor one half.

## 5. `ChiFeasible`

```lean
def ChiFeasible (xbar χ₀ : Fin n → ℝ) : Prop :=
  ∃ z, χ₀ - xbar = S.Sig0 *ᵥ z
```

**Rendered meaning.** The initial estimate displacement χ₀ − x̄₀ must lie in range Σ₀.

**Paper counterpart.** P_T imposes U₂ᵀ(χ(0) − x̄₀) = 0. For symmetric Σ₀ this is the same range constraint.

## 6. `chiOpt`

```lean
noncomputable def chiOpt (x₀ xbar : Fin n → ℝ) (T : ℕ) : Fin n → ℝ :=
  x₀ - S.optInit (x₀ - xbar) T
```

**Rendered meaning.** The optimal initial estimate is the true nominal initial state minus the optimal initial error.

**Paper counterpart.** This is x̂(0 | T), the initial component of the P_T minimizer.

## 7. `chiOptCtrl`

```lean
noncomputable def chiOptCtrl (x₀ xbar : Fin n → ℝ) (T k : ℕ) :
    Fin m → ℝ :=
  S.glq.optCtrl (S.optInit (x₀ - xbar) T) T k
```

**Rendered meaning.** This is the optimal process-noise decision at time k for the horizon-T problem.

**Paper counterpart.** This is ŵ(k | T), one component of the optimal sequence ŵ_T.

## 8. `chiOptTraj`

```lean
noncomputable def chiOptTraj (x₀ xbar : Fin n → ℝ) (T k : ℕ) :
    Fin n → ℝ :=
  S.A ^ k *ᵥ x₀
    - S.glq.traj (S.optInit (x₀ - xbar) T) (S.chiOptCtrl x₀ xbar T) k
```

**Rendered meaning.** The optimal estimate at time k is the nominal true state Aᵏx₀ minus the optimal error trajectory.

**Paper counterpart.** This is x̂(k | T), with x̂(T) defined as x̂(T | T).

## 9. `chiOptLim`

```lean
noncomputable def chiOptLim (x₀ xbar : Fin n → ℝ) : Fin n → ℝ :=
  x₀ - S.optInitLim (x₀ - xbar)
```

**Rendered meaning.** The infinite-horizon initial estimate is x₀ minus the limit of the finite-horizon optimal initial errors.

**Paper counterpart.** Proposition `prop:infhor`, item `it:zlim`, defines x̂(0 | ∞) as the limit of x̂(0 | T).

## 10. `chiOptCtrlLim`

```lean
noncomputable def chiOptCtrlLim (x₀ xbar : Fin n → ℝ) (k : ℕ) :
    Fin m → ℝ :=
  S.optCtrlLim (x₀ - xbar) k
```

**Rendered meaning.** For each fixed k, this is the limiting optimal process-noise decision as the horizon tends to infinity.

**Paper counterpart.** Proposition `prop:infhor`, item `it:zlim`, defines ŵ(k | ∞) = lim_T ŵ(k | T), with T taken beyond k.

## 11. `chiOptTrajLim`

```lean
noncomputable def chiOptTrajLim (x₀ xbar : Fin n → ℝ) (k : ℕ) :
    Fin n → ℝ :=
  S.A ^ k *ᵥ x₀
    - S.glq.traj (S.optInitLim (x₀ - xbar)) (S.optCtrlLim (x₀ - xbar)) k
```

**Rendered meaning.** Roll out the limiting initial decision and limiting control sequence, then subtract its error from the nominal state.

**Paper counterpart.** Proposition `prop:infhor`, item `it:xTT`, calls this x̂(k | ∞), the trajectory generated by the limiting pair (x̂(0 | ∞), ŵ_∞).

## 12. `chiInfCost`

```lean
noncomputable def chiInfCost (x₀ xbar χ₀ : Fin n → ℝ)
    (ω : ℕ → Fin m → ℝ) : ℝ :=
  quadForm (symmPinv S.hSig0.1) (χ₀ - xbar)
    + ∑' k, (quadForm S.Qi (ω k) + quadForm S.Ri (S.chiResid x₀ χ₀ ω k))
```

**Rendered meaning.** This is the infinite sum version of `chiCost`, including the prior term and every stage cost.

**Paper counterpart.** Proposition `prop:infhor`, item `it:Vlim`, defines V_∞ with the same prior and infinite stage sum, subject to the same dynamics and support constraint. Lean again uses twice the paper's one-half-scaled cost.
